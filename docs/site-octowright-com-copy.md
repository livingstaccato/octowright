## Homepage Positioning

### Section: Built for Development and Testing
Octowright is not just browser control. It is a development and testing workflow for multi-session web behavior.

Use it to:
- Reproduce bugs that only appear with multiple users active at once
- Run cross-engine checks in Chromium, Firefox, and WebKit in parallel
- Save realistic flows as macros, then replay them in repeatable verification runs
- Produce JUnit and replay artifacts for CI and incident review

### Section: Why Teams Use It

#### Multi-session realism
Launch coordinated participants as a scenario (players, monitor, spectator) instead of faking concurrency with a single tab.

#### Replay and evidence
Every action is recorded. Re-run flows, export scripts, and inspect timeline evidence in the local dashboard.

#### CI-friendly checks
Run verify macros as tests and publish JUnit output into existing pipelines.
