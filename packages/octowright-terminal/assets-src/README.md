# octowright-terminal renderer (build-only)

This is a standalone npm project, deliberately **not** a member of the root
npm workspace and **not** a dependency of `packages/octowright-frontend`.
Its only job is producing one committed artifact:

```
../src/octowright_terminal/assets/renderer.js
```

Core's dashboard serves plugin assets as bare static files
(`http/routes/plugin_assets.py`) -- there is no bundler on that path, so the
output must be a single self-contained ES module with `@xterm/xterm` and its
two addons (`addon-web-links`, `addon-unicode11`) inlined, including xterm's
own stylesheet (inlined as a JS string and injected via a `<style>` tag at
mount time -- see `src/css.d.ts` / `src/renderer.ts`).

A Python wheel has no npm build step at install time, so `renderer.js` is a
**committed artifact**, not a build output regenerated by CI. Rebuild it
after editing `src/renderer.ts`:

```bash
cd packages/octowright-terminal/assets-src
npm install   # first time, or after a dependency bump
npm run build # tsc --noEmit, then esbuild bundle+minify -> ../src/.../assets/renderer.js
```

Then re-run both test suites and re-commit the rebuilt file alongside the
source change:

```bash
cd ../../.. && uv run --active --no-sync pytest packages/octowright-terminal/tests/test_frontend_asset.py -v --no-cov
cd packages/octowright-frontend && npm test
```

The runtime contract this renderer implements is published at
`packages/octowright-frontend/src/plugin-contract.d.ts`. `src/renderer.ts`
keeps a deliberate structural COPY of the relevant shapes rather than
importing that file, for the same reason the contract file itself gives for
declaring `SessionEvent` separately from core's internal `RecordingEvent`: a
plugin should not have to reach into core's source tree to build against the
published contract. Drift between the copy and the real contract is caught
at runtime by `packages/octowright-frontend/tests/terminal-plugin-renderer.test.ts`,
which imports the BUILT `renderer.js` and drives it through
`mountStream` → `feed` → `destroy` against the real shapes.
