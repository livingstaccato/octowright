Octowright playground

A small target site used by recorded demo bundles. Pages below host the shared state for multi-browser demos.

  • Shared canvas — tiles claimed by multiple participants, broadcast over SSE.
  • Form flow — three-step form. Each Next button posts an event.
  • Monitor dashboard — read-only stream of form-step events.

Not a public site. Boots on http://127.0.0.1:7900 while a demo records.
